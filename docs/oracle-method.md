# Independent consumer method

The application lexer, parser, evaluator, guard compiler and enumerator live in `src/core.mjs`. They do not import editor code. The test oracle bundles 56 unmodified files from Microsoft's official VS Code 1.96.4 commit `cd4ee3b1c348a13bafd8f9ad8060705f6d4b9cba`; all source bytes are checked against `oracle/upstream-lock.json` before use. See [oracle/README.md](../oracle/README.md) for details.

`tools/oracle.mjs` reads artifact files, not internal ASTs. It independently enumerates the project model, verifies the original artifact against the project, parses conditions through diagnostic upstream Parser and production ContextKeyExpr, resolves keys through upstream KeybindingParser/USLayoutResolvedKeybinding for the declared platform, then runs KeybindingResolver over original, compiled, and reversed-compiled arrays. Args, args-presence and fall-through are included. It verifies chosen priorities, source-map coverage, disjoint matching and the CSV changes. No production parser/evaluator is used to determine an oracle winner.

The exact fixture consists of generic, Python and selection rules for ctrl+alt+k. Boolean focus/selection plus three language states create 12 contexts. Python-first priority changes one result, leaves six fall-through contexts, and handles four missing-language contexts. Generated differential tests create independent actual artifact sets from app output and compare them to the pinned consumer. Mutation tests establish that corrupted args, missing contexts and overlapping guards are detected.

The browser acceptance harness extracts the actual downloaded ZIP, supplies the known input fixture independently, and reruns the upstream oracle. The native harness consumes those same artifact bytes in fresh disposable profiles. It downloads the official Linux x64 distribution only after checking pinned release metadata and verifies SHA-256 and installed commit. Each of 12 contexts is set through custom whenfold keys, followed by an actual X11 ctrl+alt+k keypress. It captures exactly the three harmless fixture command callbacks and args, first for original then compiled files. It refuses non-fixture command IDs and does not use a real user profile. Sandbox bypass is forbidden.

The test scope is specific: pinned VS Code 1.96.4 source and optional native Linux/US-X11 consumer. It does not establish every later editor version, physical layout, system shortcut, built-in/extension binding order, context reachability or real command effect. Preparing a native test is not evidence it ran. Consult the verification status for stage outcomes.
