Coverage / 検証範囲
  • Only the supplied ordered rules; unknown built-ins and extensions are outside coverage.
  • Contexts are declared logical combinations, not proof they can occur in the editor.
  • Commands and arguments are preserved as data. This tool does not execute commands or change settings.
  • Default behavior preserves imported bottom-to-top winners. Changed priorities are explicit user choices.
  • Source comments and formatting are not preserved. Review before applying the file.
  • 単一キー操作・宣言済みコンテキストのみ。未入力の組込み規則、拡張機能、実際の到達可能性は対象外です。
