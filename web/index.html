    このワークベンチが保証する範囲

    最大 100 ルール、4,096 個の型付き有限コンテキスト。単一ストロークのキーのみ。宣言したモデルと対応する条件式の範囲で解析します。

    未知の組み込み・拡張機能のルール、実際のキーボード配列、エディタの到達可能状態は対象外です。コメントや元の整形は保存されません。

    コマンドの実行、VS Code の設定変更、外部送信は行いません。出力を確認し、バックアップを取ってから手動で導入してください。

    WhenFold / 優先順位を、明示する。依存なし。送信なし。オフライン対応。
